## 简介与研究价值

本书围绕计算控制与连续物理演化的共同建模、规格表达和演绎验证展开。混合程序描述离散步骤与微分方程，微分动态逻辑（dL）表达程序执行后的性质，不变式与证明规则支撑安全性推理；后续内容扩展至混合博弈、统一替换及运行时验证。上述主题和章节对应关系依据[作者目录](https://www.lfcps.org/lfcps/index.html)整理。

对本读书会而言，学习重点是把“系统应该安全”逐步变成可审阅的模型、假设、规格与证明义务。它为CPS建模、控制软件验证和智能系统的安全约束研究提供基础。将这些方法用于HCPS时，人类行为、观察能力、决策权及环境不确定性需要另行建模和论证；本档案不将教材表述为一套现成的HCPS人因理论。

建议具备基础逻辑、程序语义、微积分和常微分方程知识；缺失部分可在相应章节前补读。具体分组由[研读计划](schedule.md)确认。
