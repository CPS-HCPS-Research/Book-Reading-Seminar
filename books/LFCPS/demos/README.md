# LFCPS实验与验证

当前没有已实现或已验证Demo，也没有已测试的KeYmaera X环境。本目录为后续原创实验提供入口。

每个实验直接创建为 `chXX-topic/`，从[Demo模板](../../../templates/demo.md)复制README，放入源代码、模型及必要的小型证据。README须能指导另一位成员从环境配置到结果判读。不要提交工具安装包、依赖目录、模型全集、缓存或密钥。

KeYmaera X相关工作可围绕混合系统建模、dL规格表达或证明义务展开。以下仅为准备要求，不是已运行实验：

1. 从[官方安装、教程与文档](../resources.md)选择工具版本；记录操作系统、Java和所需算术后端版本及许可要求。
2. 说明模型状态、离散/连续行为、演化域、初始条件、安全性质以及简化假设；标明对应章/节。
3. 给出可重复的导入、命令或GUI操作步骤，保存模型与适用的证明脚本；有GUI步骤时写清入口和参数。
4. 将预期输出、实测输出和独立复核分开；记录是否仍有未闭合证明目标。无法安装时写明阻碍，保留“未运行”。
